### Quick Start Commands:

- **Local Development:** `run_dev.bat`
- **Docker Production (PostgreSQL + Redis):** `docker compose up -d --build`
- **Docker Standalone (SQLite):** `docker compose -f docker-compose.sqlite.yml up -d --build`
