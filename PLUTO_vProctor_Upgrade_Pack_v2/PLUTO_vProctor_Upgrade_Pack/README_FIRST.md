# PLUTO vProctor — Upgrade Pack v2

This pack upgrades the existing project additively; it does not replace the current application.

## Included scope
- Candidate login and separate admin login.
- Resume upload or manual profile entry, editable parsing and skill extraction.
- Explainable fresher/entry-level job recommendations for EVERY authenticated candidate, regardless of AI interview mode, admin-hosted mode, both or neither.
- Admin-hosted online rooms with invitation link/code, question dataset upload, ordering and live controls.
- Reuse existing offline preparation, calibration, proctoring, recording, analysis and report pipeline.
- Interview scheduling/calendar and optional reminders.
- Admin analytics dashboard.
- Candidate skill-development roadmap.
- Reliability, security, privacy, fairness and deployment improvements.

## Start here
1. Read `SEVEN_STEP_EXECUTION_MANUAL.md`.
2. Extract/merge this folder into the existing repository root.
3. Let Antigravity install GSD, Superpowers and Context7 using `ANTIGRAVITY_TOOLS_SETUP.md`.
4. Give Antigravity the complete `prompts/ANTIGRAVITY_MASTER_PROMPT.md`.
5. Antigravity must perform Phase 0 audit and cleanup proposal first, then stop for approval.

## Safety
Never delete/overwrite databases, migrations, datasets, model weights, fixtures, recordings or reports as cleanup. Inventory first, back up, verify restore, obtain approval, then perform only explicitly approved changes.
